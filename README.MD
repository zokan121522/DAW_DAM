# 📘 Test LM · Plataforma de Práctica en un Solo Archivo

## 🎯 Descripción

Este proyecto es una **plataforma de práctica y autoevaluación** para **Lenguajes de Marcas (HTML, CSS, XML, LM)** y **Java**, pensada para estudiar de forma **rápida, directa y sin dependencias externas**.

👉 **Todo el sistema está contenido en un único archivo HTML**, lo que facilita enormemente su uso, copia y práctica en cualquier entorno.

---

## ✅ ¿Por qué todo en un solo archivo?

El proyecto está diseñado **a propósito** como archivo único por los siguientes motivos:

- 📦 **Portabilidad total**  
  Copias el archivo y funciona inmediatamente.

- 🌐 **No necesita servidor**  
  Se abre directamente en el navegador.

- 🔒 **Sin instalaciones ni librerías externas**  
  No requiere Node, npm, frameworks ni conexión a Internet.

- 🧠 **Ideal para estudiar**  
  Menos fricción técnica = más tiempo practicando.

- 🧪 **Perfecto para exámenes**  
  Funciona offline y sin límites.

---

## 🧩 Qué incluye el archivo

Todo integrado en un solo `.html`:

- 📚 Preguntas tipo test organizadas por temas:
  - HTML
  - CSS
  - Lenguajes de Marcas
  - Java
- 🔀 Generación aleatoria de preguntas
- 🎯 Corrección automática
- 📊 Resumen de resultados
- ❌ Registro de errores
- 📝 Sistema de notas persistentes
- 📌 Guardado de progreso
- 🎨 Estilos unificados para todos los ejercicios

---

## 🛠️ Organización interna

Aunque es un solo archivo, está estructurado claramente:

- **HTML** → estructura y navegación
- **CSS embebido** → apariencia consistente
- **JavaScript** → lógica de quizzes, corrección y progreso
- **Arrays de preguntas** → fáciles de ampliar o modificar

👉 Puedes añadir o cambiar preguntas **sin tocar la lógica**.

---

## ▶️ Cómo usarlo

1. Abre el archivo `.html` en tu navegador
2. Selecciona un tema desde el menú
3. Elige cuántas preguntas generar
4. Responde y corrige
5. Revisa resultados y explicaciones
6. Repite hasta dominar el temario
